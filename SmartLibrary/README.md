# SmartLibrary / Ақылды кітапхана

React Native + Expo + TypeScript. Оқу жобасы: №1–9 зертханалық жұмыстар біріктірілген.

## Запуск (Windows 11, VS Code)

1. Установите Node.js LTS и Expo Go на телефон.
2. Распакуйте ZIP, откройте папку `SmartLibrary` в VS Code.
3. В терминале PowerShell выполните:

```powershell
npm.cmd install
npx.cmd expo start -c
```

4. Телефон и ПК должны быть в одной Wi-Fi сети. Отсканируйте QR через Expo Go. Для браузера нажмите `w` (или `npx.cmd expo start --web`).
5. Для проверки TypeScript: `npx.cmd tsc --noEmit`.

При проблемах с сетью попробуйте `npx.cmd expo start --tunnel` (может потребовать установки `@expo/ngrok`).

## Возможности
- Учебный логин (любой логин, пароль минимум 6 символов; **не настоящая серверная аутентификация**).
- Главная, каталог, избранное, новости, профиль; Stack + Tabs.
- Добавление, поиск, удаление книг; повторно используемые BookCard, Field, Button.
- Сохранение книг, избранного, языка, темы и масштаба текста в AsyncStorage.
- Светлая и тёмная темы, қазақша / русский.
- REST GET `https://jsonplaceholder.typicode.com/posts?_limit=10`: загрузка, ошибки, повтор, pull-to-refresh. **Это демонстрационные записи, не реальные новости библиотеки.**
- Форма регистрации на мероприятие: имя от 3 символов, группа, тип, дата не в прошлом, 1–5 участников, согласие. Регистрация сохраняется локально, **не отправляется на сервер**.

## Соответствие лабораторным
1. Expo/Node/TypeScript — стартовый проект.
2. View/Text/Pressable, профиль.
3. Props/useState/FlatList/TextInput, добавление/поиск/удаление.
4. Login, проверка пароля, StyleSheet и карточки.
5. Stack + Bottom Tabs + передача `id` в Details.
6. Папки components/context/data/screens/types, типизированные компоненты; Git: `git init`, `git add .`, `git commit -m "SmartLibrary labs 1-9"` (при наличии Git).
7. Context API + AsyncStorage, тема, размер шрифта.
8. REST API, GET, загрузка, ошибка, FlatList, обновление.
9. Форма регистрации, отдельные ошибки полей, проверка даты и согласия.

## Тестирование
1. На экране входа пустые поля / короткий пароль вызывают ошибку.
2. Войти с `student` / `123456`.
3. Найти `Абай`, добавить книгу, открыть Details, отметить избранное, удалить.
4. Переключить язык, тему, шрифт; перезапустить и убедиться, что настройки сохранились.
5. Открыть новости с интернетом, обновить жестом вниз.
6. Открыть регистрацию, проверить ошибки и успешную отправку с будущей датой.

## Ограничения
Это учебный локальный прототип. Не храните реальные пароли; авторизация демонстрационная. Интернет нужен для REST API. Реальные книги/события не синхронизируются с сервером.
